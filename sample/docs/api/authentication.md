# API Authentication

Learn how to authenticate with GROWI API.

## Access Token

You need to generate an access token from your GROWI instance.

### Steps

1. Go to your GROWI settings
2. Navigate to API settings
3. Generate a new access token
4. Copy the token to your configuration file

## Security

- Never commit your access token to version control
- Use environment variables or config files
- Keep your `.gitignore` updated
